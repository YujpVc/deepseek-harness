# PPT 助手 · 产品需求文档（PRD）

> 版本：v1.0 · 状态：待评审
> 定位：一条龙 PPT 生成助手 —— 需求分析 → 内容 → 排版 → 美化 → 配图 → 图表 → 交付可编辑 `.pptx`

---

## 1. 产品概述

### 1.1 一句话定位
用户只用说清「我要做什么 PPT、给谁看、讲多久」，助手自动完成需求分析、大纲、文案、排版、美化、配图、图表，最终交付**可编辑的 `.pptx` 文件**。

### 1.2 核心价值
| 痛点 | 现有做法 | 本产品 |
|------|----------|--------|
| 不知道怎么写 | 套模板硬填 | 自动生成大纲 + 文案 |
| 排版丑、费时间 | 手动调 | 自动排版 + 统一视觉体系 |
| 找图难、怕侵权 | 乱搜图 | 真实图优先 + AI 兜底，版权可控 |
| 数据不会可视化 | 贴表格 | 自动转图表 |
| 改起来麻烦 | 重做 | 可编辑 pptx + 局部重生成 |

### 1.3 目标用户与主场景（已确认）
- **主场景**：工作汇报 / 述职（正式、数据驱动、结论先行）
- **次级场景**（后续扩展）：商业路演、教学培训、营销宣传
- **输出格式**：可编辑 `.pptx`（主）；PDF / HTML 为后续扩展
- **配图策略**：混合 —— 优先联网搜真实图，缺失/不合规时用 AI 生成兜底

## 2. 核心工作流（端到端）

```
用户输入需求
   │
   ▼
① 需求澄清（主动提问，缺什么问什么）
   │
   ▼
② 内容生成（主题 → 大纲 → 逐页文案 + 演讲备注）
   │
   ▼
③ 版式排版（每页结构：封面/目录/章节/内容/图表/结尾）
   │
   ▼
④ 视觉美化（配色 / 字体 / 图标 / 图表 / 图片，统一风格）
   │
   ▼
⑤ 交付导出（可编辑 .pptx，含备注、图表可编辑、图片内嵌）
   │
   ▼
⑥ 迭代修改（换主题 / 改单页 / 重写某段，局部重生成）
```

## 3. 功能需求

### 3.1 需求澄清（F1）
- 首次输入后，助手**主动提问**补齐缺口，而不是一次性瞎猜。
- 必问项：**主题/标题、受众、用途、时长/页数、品牌色、是否有原始数据或素材**。
- 缺省值策略：未明确时给出合理默认，并在生成结果里标注「此处按默认处理，可改」。

### 3.2 内容生成（F2）
- 生成**大纲**：结构化层级（章 → 节 → 页），结论先行。
- 生成**逐页文案**：每页「标题 + 3~5 条要点 + 过渡句」。
- 语气切换：正式汇报 / 简洁 / 有感染力（可指定）。
- 生成**演讲备注**（speaker notes）：每页一段提示语。
- 信息密度控制：每页要点不堆砌，文字不超过阈值。

### 3.3 排版（F3）
- 内置版式库（针对工作汇报）：
  - 封面页、目录页、章节分隔页、正文页（结论 + 论据）
  - 数据页（图表 + 解读）、对比页、时间轴页、结尾/致谢页
- 自动选择版式：根据该页内容类型（文字/数据/对比/流程）自动匹配。
- 支持**单页更换版式**。

### 3.4 视觉美化（F4）
- **配色方案**：自动生成主题色（可绑定品牌色）；工作汇报默认专业稳重色系。
- **字体体系**：中英文字体配对 + 标题/正文/注释三级字号层级。
- **图标**：为要点自动配图标。
- **图表**：数据自动转柱状/饼图/趋势图，图表随数据可编辑。
- **统一风格**：全篇一致，不出现「每页风格不同」的拼接感。

### 3.5 配图（F5，已确认混合策略）
- **优先级**：真实图优先，AI 生成兜底。
- 真实图：联网搜索，**过滤版权**（标注可商用/需署名/不可用）。
- AI 兜底：真实图缺失、不相关或版权不合格时，用 AI 生成同风格图替代。
- 图片处理：统一裁剪、统一色调/滤镜、去背景、去水印。
- 每张图附**来源标注**（合规需要）。

### 3.6 交付导出（F6）
- 主交付：**可编辑 `.pptx`**（PowerPoint / WPS 均可用）。
- 要求：
  - 图表是原生可编辑图表（非截图）。
  - 文字是真文本（可选中、可改、可查重）。
  - 图片内嵌进文件（单文件即可分享）。
  - 演讲备注写入备注栏。
- 可选：导出 PDF（防跑版）、图片版预览。

### 3.7 迭代修改（F7）
- 一键换主题/配色（内容不变，视觉重生成）。
- 单页修改（「第 3 页改成时间轴」「这段写得更简洁」）。
- 局部重写（只改某段文案，不动其余）。
- 版本对比：保留历史版本，可回退。

## 4. 非功能需求

| 维度 | 要求 |
|------|------|
| 完善度 | 生成结果直接可用，无需大改（目标：≥90% 可直接交付） |
| 一致性 | 配色/字体/风格全篇统一 |
| 可编辑性 | pptx 全要素可编辑 |
| 合规 | 图片版权可追溯，字体可商用 |
| 响应速度 | 从需求到初稿 ≤ 几分钟量级 |
| 稳定性 | 中文字体、图表、图片不丢、不乱码 |

## 5. 技术方案建议（实现层面）

| 模块 | 建议方案 |
|------|----------|
| 内容生成 | 大模型（大纲 + 文案 + 备注） |
| pptx 生成 | `python-pptx`（原生图表、文本框、图片全可控） |
| 图表 | `python-pptx` 原生 chart（可编辑）或 `matplotlib` 生成后内嵌 |
| 真实图 | 图片搜索 API（Unsplash / Pexels 等可商用源） |
| AI 兜底图 | 文生图模型（按主题生成同风格配图） |
| 配色/字体 | 内置主题预设 + 用户品牌色覆盖 |
| 交付 | 单文件 pptx 打包 |

---

## 6. 里程碑（Roadmap）

- **M0**：单页 demo —— 输入需求 → 生成 1 页可编辑 pptx（验证技术链路）
- **M1**：全流程 MVP —— 大纲 + 文案 + 基础排版 + 配色 → 完整 pptx
- **M2**：美化增强 —— 图表 + 图标 + 版式库 + 多主题
- **M3**：配图 —— 真实图搜索 + AI 兜底 + 版权标注
- **M4**：迭代能力 —— 单页修改、换主题、版本管理
- **M5**：多场景扩展 + PDF 导出

## 7. 待确认问题（Open Questions）

1. **页数/时长习惯**：你一般做多少页？对应多长演讲？
2. **品牌规范**：是否有固定的公司配色 / Logo / 字体要绑定？
3. **数据来源**：汇报里的数据，是你提供原始数据，还是助手帮你编造合理示例数据？
4. **运行形态**：希望是「命令行/脚本」还是「网页界面（在本 GUI 内交互）」？
5. **交互粒度**：更想要「一次给我成品」还是「分步骤、每步可确认」？
6. **图片预算**：真实图（免费商用源）够用，还是需要付费图库接入？

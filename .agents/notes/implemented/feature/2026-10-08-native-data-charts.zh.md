# Agent Note: PPT 助手中的可编辑数据图表

Status: implemented

[English](2026-10-08-native-data-charts.md) | 中文

## Problem

通用 PPT 生成器需要表达构成、趋势和变量关系的图表，以及类别对比。图型选择有限、标签不清和图表截图会使数据难以理解与编辑。

## Decision

共用的[图表模块](../../../../ppt-assistant/charts.py) 读取内联 JSON 或显式 CSV 数据，校验后生成十二种 PowerPoint 原生图表，并内嵌工作簿。[生成器](../../../../ppt-assistant/build_deck.py) 在普通生成与参考模板扩展中提供单图页及二至四图组合页。严格模板填充保持既有行为。图表数据处理和绘制由引擎负责，不依赖工作区脚本。

缺测保留为空，排名同时移动标签与数值。校验拒绝非有限数、不完整 CSV、混合数据输入、无效构成数据，以及隐藏观测值或堆叠总量的坐标范围。条形与面积图保留零基准。百分比堆叠保留源数量，值轴使用 0–1，默认不显示数量标签；显式数量标签仍使用原始单位。

[助手模式](../../../../profiles/yujp-web/presets/ppt-assistant/agent.cordis.yml) 按页面问题选择图型，数据密集的汇报优先使用原生图表，并要求检查来源、单位和渲染标签。统一样式提供系列配色、稀疏分类刻度、高亮、坐标标题和多图组合；密集条形图拒绝生成，避免压缩成不可读标签。

## Alternatives considered

**嵌入图表位图。** 能表达更多专用图型，但失去可编辑系列，并在引擎外重复维护数据展示。

**增加绘图服务或依赖。** 已有 PowerPoint 库无需新服务或依赖即可提供所需图型和内嵌工作簿。

## Verification

[无密钥示例](../../../../ppt-assistant/examples/chart_report.json) 用明确标注的示例数据覆盖全部图型，其[快照](../../../../ppt-assistant/examples/chart_report.expected.json) 记录可见文字、原生图型、系列数值、XY 坐标与气泡面积。[测试](../../../../ppt-assistant/test_charts.py) 调用 CLI，重新读取原生数据，核验内嵌工作簿，并检查 CSV、缺测、无效输入、零基准、模板封面保留、多图几何与已有输出保护。结构与几何检查先于渲染复核，图表内部标签仍需视觉检查。

## Consequences

用户可在交付 PPTX 中编辑图表及数据。容量取决于面板尺寸，分类刻度可稀疏显示而不丢弃观测值。固定调色板、六系列与八扇区限制适合可读的商务图表；专用科研图需要单独的产物。LibreOffice 渲染提供视觉依据，WPS 交互编辑仍需在应用内验证。

# Agent Note: 参考模板生成原生转正汇报

Status: implemented

[English](2026-10-08-native-probation-reference-decks.md) | 中文

## 问题

四页转正模板可以规定必要主题和背景，而不限定最终汇报的页数。重复使用图加卡片版式并嵌入预制图表，会使正文难以编辑、照片重复、数据来源不清晰。

## 决策

仓库内的[生成器](../../../../ppt-assistant/build_deck.py)支持 `--probation` 和 `meta.deck_mode: native_v2`。它原样保留模板第一页、继承母版，以原生文字、图形和图表组成正文。这组固定版式接受 13.333 × 7.5 英寸模板。正文照片按文件字节去重，包括不同路径下的副本；抓取配对对照可以在优化前后两个面板中使用同一轮照片。结束页使用封面布局。严格模板填充保持为独立模式。

[实验数据读取器](../../../../ppt-assistant/grasp_evidence.py)以统一裁剪区域、调色板和米制范围读取深度数组，并通过对应相机标定投影记录中的抓取变换和开合。线框保留为可编辑的 PowerPoint 连接线。显示用指部尺寸不代表实物标定或碰撞安全结论。文字检查器排除两条无文字线框之间的相交，同时保留文字遮挡检查。

`visual_gallery` 将原始照片及同尺寸 RGBA 候选图层作为独立、对齐的图片嵌入。每页包含三个保存帧及原生标签；`data_table` 用可编辑单元格展示数据对照。CLI 核验对齐、透明度，以及拒绝尺寸不匹配的图层且不覆盖已有文件。

紧凑的深度、位姿和性能案例在同页展示优化前、方案与优化后。保存的候选分数决定展示的位姿，候选总数与响应核验。候选和选定位姿采用相同的原生几何与样式；正文移除未使用的模板占位符和空文本框。

交付叙事先讲 WRC 现场，再讲抓取工程；每项优化按优化前、方案、优化后组织。`pose_case` 从筛选记录读取全部候选，蓝色表示通过、红色表示未通过；候选密集时使用相同几何在内存中合成，保持 PPT 可用。性能页可以说明分割、深度补全和候选生成耗时，`roadmap` 提供近期、中期、长期成长规划。

## 考虑过的替代方案

**只填模板原有页面。** 当参考模板本来就很短时，无法表达完整汇报。

**嵌入整张预制图表。** 标签和数据不能作为 PowerPoint 组件编辑，而且容易重复套用同一版式。

## 验证

[CLI 测试](../../../../ppt-assistant/test_build_deck.py)核验封面 XML 不变、图表数据及备注可编辑、重复照片拒绝、未知版式和不兼容尺寸拒绝、六组配对原生线框，以及拒绝不一致的开合统计且不覆盖已有文件。[实验数据测试](../../../../ppt-assistant/test_grasp_evidence.py)核验统一深度色标、无效深度处理、原图尺寸、物理投影，以及保留真实文字重叠检测。交付 PPT 还需要结构检查和渲染视觉复核。

## 影响

正文有多种排版，说明文字和图表数据可编辑。原生版式使用显式字段和固定几何尺寸；支持其他页面尺寸需要另一组版式。模板装饰可以在封面和结尾呼应，正文照片不得重复。
